# 品牌与平台导航修订

本修订保留手机/平板响应式、客服留言、资料与Java模拟接口适配，并补充以下检查和入口。

- 应用图标使用餐碗与时钟品牌；浏览器SVG/PNG、apple-touch、常规favicon.ico/svg/png均指向同一应用图标。商品、店铺自有头像和支付渠道标识不替换
- 页面标题避免“鲜食好店 - 鲜食好店”重复；后台、登录和旧前台组件使用同一已替换的应用Logo
- 平台侧栏提供可展开/收起的“支付接入”和“AI客服管理”，每组仅注册一次。支付含微信、银行卡、支付宝；AI含概览、配置、会话消息
- 会话消息直接打开现有客服工作台，配置页可保存配置元数据。外部AI和真实支付保持未连接，不显示虚假的服务接通状态
- 店铺已有直接客服入口；订单详情另有“联系本店客服”直聊与原有订单留言入口。聊天按店铺归属，订单号仅作为已核对的页面咨询上下文，不冒充服务端订单绑定，也不自动发送消息
- 新的Vue DOM回归验证折叠行为、子页面、商家权限隔离、品牌资源、店铺/订单直聊、商家回复和顾客未读/已读；订单与信用状态保持不变

历史页面出现旧品牌与缺少分组，需要同时核对部署版本。源码提交不等于站点更新，应以对应版本的成功部署记录为准，不将源码完成当作页面已经上线。

默认网页为本机演示，标明后端未连接；Java模式须由用户明确连接模拟服务。真实后端未托管时，不代表跨设备客服同步。

## 警告与未验收部分

- 构建有大于500 kB的分块提示；这不阻止构建，但仍需按生产性能目标进一步拆包、测量首屏和移动设备表现
- 依赖安装出现 `whatwg-encoding` 和 `lodash.isequal` 的上游弃用提示；未运行完整依赖漏洞审计，不能声称生产安全已验收
- DOM 点击检查不是浏览器像素/布局、移动设备或线上访问验证
- 未重跑真实 HTTP、MySQL/JDBC、完整后端多模块打包、完整芋道管理后台或38张领域表执行
- 新餐饮 UI 仍未连接 Java/96端点，无真实支付、AI、生产认证或多设备同步；所有资金结果为明确的模拟状态
- 旧 `docs` 中的150项状态、运行日志和旧安全清理报告分别保留其原时间和范围，不因本版发布自动转为通过
